# Building HuntBot — diagram sources

Source files for the images on the AI-generated **Building HuntBot** page
(`/projects/building-huntbot`, a `project` document in Prismic). The page is meant
to be updated as the site changes.

Every image is generated by `build.py` in the same hand-drawn ink style as HuntBot's
avatar (`src/lib/assets/huntbotlogo.svg`). Keep them visual-first: the drawing carries
the idea, and labels stay short. Technical terms are fine on the pipeline figures
(the post links out to the sources), but skip full sentences.

| Image | What it shows |
|---|---|
| `hero` | Highlight + meta image: HuntBot and the things it draws on |
| `system-map` | How the services fit together |
| `pipeline` | The full chat flow, step by step |
| `hyde` | Why HyDE helps: the made-up answer lands closer to real pages |
| `rerank` | 16 nearest chunks → cross-encoder → top 5, max 2 per page |
| `prompt-cache` | The shared, cached prompt prefix vs. per-turn details |
| `timeline` | Commits per month, with the big moments called out |

## Updating

1. Edit `build.py`. For the timeline, update `COMMITS` (the command to get the
   counts is in the file).
2. Run `./render.sh` (pass a Chromium path if `chromium` isn't on your PATH). It
   renders every `.html` file at 2x into a PNG next to it, sized from its `<svg>`. Needs Python with Pillow.
3. Upload the new PNG to Prismic and swap it into the page's image slice, then
   update the text and the "Last updated" date in the AI-generated note at the top.

Labels use the site's Favorit font from `src/lib/assets/fonts`, with the stone
grays and the `mud` accent from `tailwind.config.js`.
